# М-05: сквозной учебный расчёт

Дата: 08.11.2026. Статус: базовый комплект эталонов проектирования подготовлен, не исчерпывающий набор тестов и не расчёт реальной организации. Данные ниже — синтетические числовые входы. Условные идентификаторы не являются кодами мер ГОСТ, не импортируются в каталог и не доказывают полноту нормативного состава.

## Условия

Один контур, один зафиксированный уровень защиты. Для арифметического примера рассматривается один процесс со структурой из четырёх подпроцессов, соответствующей структуре процесса 1. T = 1 — учебное условие, не согласованное нормативное исключение остальных процессов. Никакого реального заключения о допустимости такой области здесь нет. Правила Н не моделируются; М-01 остаётся открытым. Все приведённые входы условно считаются утверждёнными, нет нерассмотренных исключений и компенсаций. Жизненный цикл включён, Z = 1 — один рассмотренный учитываемый факт.

Применяется принятый порядок: результат каждой формулы округляется до двух знаков ROUND_HALF_UP; внутри формулы слагаемые отдельно не округляются. Все исходные числа рассматриваются точно, без float.

|---|---|---|---|---|

| S2 | B1 = 1; B2 = 1; B3 = 1 | 3 | 3 | 1,00 |

Идентификаторы позиций, суммы, знаменатели, ревизии входов и округлённые оценки нужны в протоколе. Прямое среднее всех десяти входов не заменяет следующую формулу.

## 2. Выбор мер процесса: формула (2), п. 7.1

M = 4.

E_PZI = (0,50 + 1,00 + 0,67 + 0,00) / 4 = 2,17 / 4 = 0,5425 → 0,54.

## 3. Четыре направления: формулы (3)–(6), пп. 7.2–7.5

Все наборы относятся к тому же одному процессу.

| Направление | Условные оценки мер | Сумма / количество | Оценка |
|---|---|---|---|
| Планирование, (3) | 1; 0,5 | 1,5 / 2 | E_P = 0,75 |
| Реализация, (4) | 1; 0,5; 0 | 1,5 / 3 | E_R = 0,50 |
| Контроль, (5) | 1; 1 | 2 / 2 | E_K = 1,00 |
| Совершенствование, (6) | 0,5; 0,5 | 1 / 2 | E_C = 0,50 |

## 4. Оценка процесса: формула (8), п. 7.7

E_i = (0,54 + 0,2 × 0,75 + 0,4 × 0,50 + 0,25 × 1,00 + 0,15 × 0,50) / 2.

Взвешенная сумма внутри формулы: 0,15 + 0,20 + 0,25 + 0,075 = 0,675.

E_i = (0,54 + 0,675) / 2 = 0,6075 → 0,61.

Не округлять внутреннюю сумму 0,675 отдельно до 0,68. По таблице 1, п. 7.9, оценка процесса 0,61 соответствует второму уровню соответствия. Это не уровень защиты контура. Формулы (9)–(12) для одного контура не применяются.

## 5. Жизненный цикл: формула (7), п. 7.6

Условные оценки L1 = 1; L2 = 0,5; L3 = 1; L4 = 0,5.

E_AC = (1 + 0,5 + 1 + 0,5) / 4 = 3 / 4 = 0,75.

## 6. Итог: самостоятельная часть студента

Входы: E_i = 0,61; E_AC = 0,75; T = 1; Z = 1. Жизненный цикл оценивается.

Студент самостоятельно записал и верно вычислил:

R = (0,61 + 0,75) / (1 + 1) − 0,01 × 1 = 0,67.

Числитель: 1,36; знаменатель: 2; среднее до снижения: 0,68; снижение: 0,01; итог после округления: 0,67. Жизненный цикл включён, повторного деления среднего нет. Арифметика дополнительно проверена Decimal. По просьбе студента отдельно разобрано происхождение E_i = 0,61 по формуле (8); самостоятельным решением студента является итоговый шаг, а не все предыдущие вычисления.

## 8. Статус критериев М-05

- Самостоятельный шаг 6 завершён и проверен; повторное упражнение не требуется.
- Дополнительные эталоны структур и формул приведены в разделе 9; справочные (9)–(12) не включаются в одноконтурный алгоритм.
- Отрицательные случаи описаны как ожидаемые исходы в разделе 10; проверки приложения ещё не исполнялись. Планируемые случаи: шкала 0,5 для выбора; значения вне шкал; отсутствие утверждения/ревизия изменилась; неподтверждённый каталог; незавершённые исключения; пустой знаменатель; неопределённая обработка Н; повторный учёт дубликата; отрицательный R и округление на половине шага; изменение справочника после снимка; отсутствие жизненного цикла против реального нуля.
- Визуальная сверка форм А/В и сопоставление основных полей выполнены; точное назначение неоднозначной дополнительной строки итоговой В.14 и оформление подписей остаются явно отмеченными ограничениями перед реализацией отчёта.

Шаги 1–6 арифметически разобраны в тексте и дополнительно проверены временным скриптом Decimal с явными ожидаемыми значениями. Это ещё не независимая вторая реализация или unit-тесты приложения. Актуальная граница завершения М-05 указана в разделе 11.

### Замечания по сверке форм

В предоставленной форме В.8 для процесса 8 итоговая подпись имеет индекс 5. Это обнаруженная несогласованность подписи: принадлежность итога определяется заголовком процесса 8 и правилом п. 7.1, а не копированием индекса 5. Наличие официальной поправки по этой подписи не проверялось. В будущей модели нужны явные идентификаторы процессов; исправление шаблона отчёта должно сопровождаться пояснением, без заявления о дословном воспроизведении официальной формы.

В В.14 присутствует дополнительная итоговая строка, текст которой упоминает нарушения, а также отдельные строки Z и R. Её нельзя автоматически назвать «средним до снижения» только по расположению. В техническом протоколе среднее до снижения, Z, величина снижения и R разделены однозначно формулой (13); буквальное сопоставление дополнительной строки формы требует уточнения перед экспортом. Это ограничение не меняет формулу расчёта.

| N-09 | Один факт связан с тремя ответами и двумя файлами | При решении «учитывать» увеличить Z на 1, не на число связей |

| N-15 | R после снижения отрицателен | Сохранить результат, округлить ROUND_HALF_UP; не отсекать нулём и не применять таблицу 1 к R |

Это спецификация будущих тестов и проверок, а не отчёт об их прохождении. В частности, требования N-01/N-02 должны подтверждаться вызовом реального валидатора при реализации; проверка принадлежности числа множеству во временном скрипте этого не доказывает.

## 11. Граница завершения М-05

Базовый комплект М-05 для проектирования подготовлен: первый сквозной пример с самостоятельным итогом студента, арифметические эталоны всех формул (включая справочные), сопоставление форм А/В, матрица будущих отрицательных проверок. Это не релизная приёмка ядра. Дополнительные комбинации, автоматизация тестов, повторяемые независимые контрольные расчёты и подтверждение каталога требуются на этапах 3/6.

Нерешённое правило Н (М-01) не закрывается числовыми примерами. Замечания по форме В.14 и подписи В.8 остаются ограничениями перед созданием экспорта. Этап 0 не объявляется завершённым автоматически: организационные решения и исходные пробелы проверяются отдельно по плану.
