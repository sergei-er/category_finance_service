# Итоговый аудит этапа 0

Дата: 09.11.2026. Тип проверки: документация и локальные артефакты, не испытание приложения.

Базовое проектирование завершено с перечисленными ниже ограничениями. Это означает наличие проверяемой исходной спецификации для каркаса, а не завершение нормативной верификации или готовность продукта. Django-проект, контейнеры, миграции, каталог, расчётное ядро и экспорт пока не созданы.

## Согласованная основа

- Одна организация; один контур/уровень на обследование; история повторных обследований. Результат контура не объявляется общим результатом банка.
- Python 3.12, Django 5.2 LTS/Templates/ORM, PostgreSQL 16, Gunicorn, Nginx, Compose. Точные patch-версии проверяются перед установкой на этапе 1.
- Проверяющий создаёт черновик. Администратор назначает одного сотрудника и одного проверяющего — разных пользователей. Назначенный проверяющий начинает заполнение.
- Сотрудник предоставляет сведения и свидетельства, отправляет всю анкету. Проверяющий оценивает версии ответов, возвращает на доработку, рассчитывает, утверждает, закрывает и выпускает проект отчёта. Свои ответы утверждать нельзя, даже при совмещении ролей.
- Свидетельства могут подтверждать несколько ответов одного обследования. Перезаписи исторического файла нет. Изменённые основания требуют нового решения; повторная отправка не сбрасывает решения по действительно неизменённым ревизиям.
- Утверждённые данные фиксируются. Закрытое обследование доступно для чтения; исправления — новое связанное обследование.
- Статусы, оценки и неоцениваемость разделены. Decimal/ROUND_HALF_UP, поэтапное округление; отрицательный R не отсекается. Это зафиксированные технические интерпретации, не дополненные цитаты ГОСТ.
- Один факт может иметь несколько связей; Z — число учитываемых самостоятельных фактов, а не файлов/ответов. Автор регистрации и источник обнаружения различаются.
- Свидетельства приватны, сервер проверяет каждую операцию; база без внешнего порта, единственный вход через Nginx. Эти меры спроектированы, не реализованы.

Формы А/В сопоставлены с данными; замечания подписей сохранены. Полный нормативный каталог не сверялся.
