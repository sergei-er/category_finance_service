# Технические решения

03.11.2026 — этап 0.

1. Принят стек и модульный монолит из AGENTS.md. Отдельный frontend и REST API не нужны для серверных форм.
2. Одна организация: отдельная tenant-модель не вводится.
3. Статус, оценка и неоцениваемость разделяются: отсутствие ответа не превращается в ноль.
4. История сохраняется через версии каталога/ответов и неизменяемый снимок результата.
5. Свидетельства приватны; скачивание после серверной авторизации.
6. Результат обозначается как внутренняя оценка / проект отчёта.
7. Git: один учебный этап — рабочая ветка и небольшие проверенные коммиты; перед коммитом просматривается diff, после завершения этапа выполняется слияние в main. Git 2.53.0 доступен, но репозиторий ещё не инициализирован; .git в среде агента доступен только для чтения. Инициализацию и первый коммит выполняет студент локально по README. Исходные материалы, секреты и данные исключены через .gitignore. Remote не настроен; push автоматически не выполняется.
8. Формулы реализуются после проверки первоисточника; Decimal и явное округление. Не вводить ограничение отрицательного R нулём без нормативного основания.
