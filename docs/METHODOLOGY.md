Уточнения перед программированием:

- Визуально сверить формулы (1)–(5), шкалы 6.10 и условия 6.11–6.12, приложение Б; каталог мер проверять отдельно.
- Подтвердить порядок округления промежуточных результатов ручными примерами. Предлагаемый технический механизм — Decimal.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP); это решение реализации, а не буквальное название режима в стандарте.
- Формула (13) может дать отрицательное R при большом Z; не добавлять clamp к нулю без подтверждённого основания.
- Несколько контуров одного уровня не следует автоматически усреднять: 7.8 требует оценку по контуру/контурам одинакового уровня. Правило формирования общих входов требует явного описания области и сверки.
- Условия исключения жизненного цикла определять по области и 6.8; нулевой реальный результат сам по себе не означает исключение.

Проектные проверки полноты (из AGENTS.md, не отдельные формулы ГОСТ): все обязательные входы утверждены и относятся к проверенной версии каталога; исключения имеют решения; отсутствующие значения возвращают «результат не определён» с перечнем пробелов; нулевой знаменатель вызывает объяснимую ошибку. Проверки должны предшествовать расчёту.
