# План функциональных этапов

Каждый этап начинается объяснением, включает самостоятельный фрагмент, проверки и завершается паузой. Следующий запускается только по команде пользователя.

| Этап | Результат и критерий |
|---|---|
| 0. Проектирование | Стартовые документы; пробелы явно обозначены; ER-фрагмент обсуждён |
| 1. Каркас | Django 5.2, Python 3.12, PostgreSQL 16, Compose, Gunicorn/Nginx; страница и воспроизводимый запуск; manage.py check, ruff, тест view |
| 2. Доступ и профиль | Создание пользователей администратором, роли, один профиль; отрицательные permission-тесты и запрет второго профиля |
| 3. Каталог | Версионированный импорт подтверждённых мер; тесты применимости и неизменности истории |
| 4. Обследование | Контуры, область, ответы и ревизии; тесты неполноты, транзакций, контекста процесса |
| 5. Свидетельства и согласование | Приватная загрузка/скачивание, решения, журнал; тест IDOR, CSRF, лимитов и запрета изменений |
| 6. Расчёт | Только проверенные формулы, Decimal, протокол; независимые ручные примеры, неверные шкалы, нулевой знаменатель, исключения и округление |
| 7. Снимки и отчёт | Воспроизводимый проект отчёта из фиксированных данных; тест неизменности при обновлении каталога |
| 8. Приёмка | Полный синтетический сценарий, проверка доступа, резервное копирование и реальное восстановление, инструкция демонстрации |

Этап 0 подготовлен как проект. Визуальная сверка оставшихся формул и таблиц, подтверждение методики и самостоятельная ER-задача ещё не завершены. Этап 1 не начат.
