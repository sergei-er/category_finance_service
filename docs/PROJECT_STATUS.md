Использованный каталог остаётся неизменяемым; для нормативного завершения нужна новая подтверждённая редакция/анкета.
- Добавлены 5 тестов: права/CSRF/подтверждение, сохранность старых ответов и статуса верификации, запрет утверждения, откат пустой области, переход полного каталога. Проверены все 667 строк одного уровня на совпадение кодов, текстов и О/Т/Н с локальным пакетом; для УЗП.1 — Т. Нормативную точность OCR это не доказывает.
