# Требования — этап 0

Дата: 03.11.2026. Статус: проект для обсуждения.

Сервис внутреннего обследования одной финансовой организации. Один редактируемый профиль, несколько контуров, история обследований. Нет tenants, публичной регистрации и заключения независимой проверяющей организации.

Сценарий: администратор заводит пользователей и профиль → специалист задаёт область и контуры → выбирается проверенная версия каталога → заполняются ответы и свидетельства → проверяющий принимает решения → проверяется полнота → выполняется расчёт с протоколом → сохраняется неизменяемый снимок → формируется «Внутренняя оценка / проект отчёта».

Статус ответа, числовая оценка и обоснованное исключение хранятся раздельно. Отсутствующий ответ не равен нулю. Завершённое обследование изменяется только через новую ревизию/обследование. Исторические результаты не пересчитываются автоматически при изменении каталога.

Приёмка: воспроизводимый Compose-запуск, проверенный каталог и методика, полный синтетический сценарий, отказ при неполноте, проверки доступа к каждой операции и файлу, воспроизводимый отчёт, восстановление резервной копии. Эти функции пока не реализованы.
